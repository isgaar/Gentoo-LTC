# Inter para Gentoo-HP

Este directorio contiene las familias estáticas `Inter` e `Inter Display`
versión 4.001 tomadas del conjunto proporcionado en `kdevoid/Fonts`.

La copia fuente se identifica de forma reproducible con:

```text
Repositorio: https://github.com/isgaar/kdevoid.git
Commit: 6432e628cb73096bdb26f84839e8fd2a82e0288e
```

Se distribuyen bajo SIL Open Font License 1.1. El instalador las copia como
`root:root`, con modo `0644`, a `/usr/local/share/fonts/gentoo-hp/inter`.

`JetBrains Mono` y `JetBrains Mono NL` no se duplican aquí: Gentoo-HP las
instala mediante `media-fonts/jetbrains-mono`.
